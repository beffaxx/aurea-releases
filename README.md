# Aurea

Download the latest version from **[Releases](https://github.com/beffaxx/aurea-releases/releases/latest)**.

1. Download `Aurea-x.y.z.zip`.
2. Extract the whole folder (do not run the exe from inside the zip).
3. Start `Aurea.exe`.

When a new version comes out, Aurea tells you at start-up and asks you to download it.

**Safety:** F12 stops any macro at once. Moving the mouse to the top-left corner of the screen also stops it.
